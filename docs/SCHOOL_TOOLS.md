# Using the new school tools

## Teachers

1. Create or open a lesson in **My Lessons**.
2. Under **Curriculum & educator review**, select the academic term and week, enter the strand/sub-strand, and optionally create an ungraded offline practice question.
3. Under **Attached resources**, upload a PDF, DOCX, PPTX, XLSX or image (up to 10 MB).
4. Create and publish an assessment. Its card in **Assignments** includes a resource upload panel.
5. Open **Submissions**, read answers, download attached handwritten work, then release a grade and feedback.
6. Use **Performance reports** to filter a class/subject and export PDF or CSV.

A school administrator records educator review. Curriculum organization is not an official approval claim.

## School administrators

- **School setup:** add classes, subjects and academic terms; enroll/transfer learners.
- **Manage school:** create student, teacher or parent accounts, activate/deactivate them and assign teachers to classes and subjects.
- **Parent links:** link a parent account to the appropriate learner.
- **Devices:** register asset tags, assign learners and set inventory activation status.
- **Performance reports:** monitor released scores, lesson completion, assignment completion and follow-up flags.

The sample parent login is `parent@demo.edumate.test`, using the configured demo password. It is linked to Ama. Ordinary parent accounts use the initial password set by the school administrator.

## Students: online and offline

1. Sign in online in the learner's managed browser profile.
2. Open a lesson and choose **Save for offline reading**. Attached resources are downloaded too.
3. Open an assessment and choose **Download assessment for offline work**. Answers autosave locally and, when connected, to the server.
4. Open **Offline learning** and select the assigned tablet record if one is available.
5. Open the offline workspace. If internet access is lost, reloading the app also opens this cached workspace.
6. Study, answer ungraded practice questions, save assessment answers and attach photos/documents.
7. Choose **Queue final submission** when ready. Reconnect and synchronize. The server validates access and attempts and scores formal quizzes; it records submission only after acceptance.
8. If the session expired, sign in again and open **Offline learning** to synchronize retained work. Conflicting drafts are preserved and can be compared with the online version.

Do not clear browser data while work is pending. Offline receipt timestamps are not trusted for deadlines: synchronization after a deadline can be marked late. School inventory status does not remotely lock Android.

## Parents

Sign in to **Parent summaries** to see only the learners the school linked to your account: released grades and feedback, completed lessons and outstanding current-class assignments. No messages or emails are sent automatically.
